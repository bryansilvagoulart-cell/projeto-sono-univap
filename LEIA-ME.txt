------------------------------------------------------------
1. DESCRIÇÃO
------------------------------------------------------------

Este pacote contém o código-fonte, banco de dados, documentação
e referências utilizadas no Projeto Sono.

O sistema realiza uma análise experimental de estágios do sono
a partir de sinais de frequência cardíaca e acelerometria.

As classes utilizadas pelo modelo final são:
- Wake
- Light
- Deep
- REM

O projeto possui finalidade acadêmica e experimental.
Os resultados não representam diagnóstico médico.

3. COMO EXECUTAR
------------------------------------------------------------

1. Restaurar o banco MySQL utilizando os arquivos da pasta
   banco-de-dados.

2. Criar o usuário da aplicação utilizando:
   configurar_usuario_app.sql

3. Criar o ambiente virtual Python:

   py -3.13 -m venv .venv313

4. Ativar o ambiente:

   .\.venv313\Scripts\Activate.ps1

5. Instalar as dependências:

   pip install -r requirements.txt

6. Executar o arquivo:

   INICIAR_SISTEMA_V3.bat

7. Informar a senha do usuário projeto_sono_app quando
   solicitado.

8. Aguardar a API iniciar e depois abrir o dashboard.

Instruções mais detalhadas estão disponíveis no README.md
e no arquivo manual-de-uso.pdf.
